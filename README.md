
# Smart Digital Expense Tracker with Budget Prediction

## About the Project
Smart Digital Expense Tracker is a C++ console-based application designed to manage daily expenses, track monthly budgets, and predict future spending.

## Features
- User Registration and Login
- Add New Expenses
- View Expense History
- Category-wise Expense Report
- Monthly Expense Report
- Set Monthly Budget
- Budget Warning System
- Budget Prediction
- Search Expenses
- Delete Expenses
- File Handling for Data Storage

## Technologies Used
- C++
- Dev-C++ 5.11
- Structures
- Functions
- Arrays
- Loops and Conditional Statements
- File Handling

## How to Run
1. Download the C++ source file.
2. Open it in Dev-C++ 5.11.
3. Compile and Run using F11.
4. Register a new account.
5. Login and start managing expenses.

## Data Files
The application automatically creates:
- users.txt
- expenses.txt
- budget.txt

## Project Objective
The main objective is to help users monitor their spending habits, manage monthly budgets, and estimate future expenses.
